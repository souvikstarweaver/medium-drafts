A Single Global Key Encrypted Every Frontier Model's Reasoning

Researchers spent $720 to extract 10,000 traces and used them to train a cheaper competitor

The Stateless Architecture and Its Single Global Key

When providers like Anthropic, OpenAI, and Google shipped encrypted reasoning traces, they faced an infrastructure trade-off. Storing a unique decryption key per user, per session, or per conversation would require server-side state management at massive scale. The alternative: a single global key, shared across every request, wrapped in an AEAD envelope (Authenticated Encryption with Associated Data, a standard method for encrypting data while also verifying it hasn't been tampered with) Panfilov et al., 2026.

Think of it like a building where every apartment lock uses the same master key. The lock works. The door closes. But anyone with a copy of that key opens every unit in the building.

The AEAD envelope contains a header (model name, block type, version, key ID), a nonce (a one-time number to prevent replay), an authentication tag, and the encrypted reasoning itself. None of these fields are bound to anything contextual: not the user, not the conversation, not the API key, not the model that generated the reasoning Panfilov et al., 2026.

How the Key Enables Cross-Model Replay

The absence of contextual binding created three forms of interchangeability. An encrypted reasoning block from one request could be replayed in a different request within the same session. It could be replayed across sessions. And it could be replayed across different models from the same provider Panfilov et al., 2026.

That third property is the one that matters. A reasoning block generated by Claude Opus 4.8 could be injected into a request to Claude Haiku 4.5. The envelope looked valid. Haiku accepted it. The same pattern held across GPT-5.6 Sol and GPT-5.6 Luna, and across Gemini models, as of July 2026 Panfilov et al., 2026.

The Security Asymmetry: Frontier vs. Sibling Models

Frontier models like Opus 4.8 and GPT-5.6 Sol carry advanced refusal training. They resist direct attempts to extract their own reasoning. But their cheaper siblings, Haiku 4.5, GPT-5.6 Luna, and Gemini Robotics 1.6, do not carry the same defenses Panfilov et al., 2026.

The attack follows a simple path. An attacker captures an encrypted reasoning block from Opus. The attacker injects that block into a new request to Haiku. Haiku decrypts the block (because the key is global), reads the plaintext reasoning, and transcribes it in its response. No jailbreak of Opus is needed. The weaker model serves as an unwitting decryption oracle for the stronger model's thinking Panfilov et al., 2026.

Extracting Reasoning at Scale: Method and Cost

Each provider's models required a different extraction approach, but the core pattern was the same: capture the encrypted block, inject it into a weaker sibling, and reconcile the output.

For Claude, the researchers used Haiku 4.5 as a fuzzy decoder. They wrote a jailbreak prompt manually, used a prefill attack (pre-populating part of the model's response to steer its behavior), and then reconciled the decoded text against the original encrypted block. For GPT, they used GPT-5.6 Luna, generating up to 50 candidate decodings per block and filtering by keyword matching with an error threshold of 0.1. For Gemini, they used Gemini Robotics ER-1.6, generating up to 20 samples per block Panfilov et al., 2026.

The injection itself took three forms: current-turn injection (placing the encrypted block in the current message), prefill injection (inserting it into the model's response prefix), and past-turn injection (embedding it as a previous assistant message in the conversation history) Panfilov et al., 2026.

To measure fidelity, the researchers tested against 120 Codeforces problems, tracking token ratios between the decoded text and the original. Test sources included AIME 2025, Codeforces, and Humanity's Last Exam Panfilov et al., 2026.

The cost: $720 to decode 10,000 reasoning traces at Haiku 4.5 pricing. Total API spend for all experiments across all providers came to roughly $30,000 Panfilov et al., 2026.

The Distillation Gain: A 7.6-Point Accuracy Improvement

The extracted reasoning traces are not interesting on their own. They become interesting when someone uses them to train a smaller model.

Using the Zhang et al. (2026a) benchmark setup, fine-tuning Qwen2.5-7B-Instruct on 10,000 prompts from the OpenThoughts-114k dataset produced a MATH500 accuracy of 68.4% with answer-only distillation (training the student on correct answers without showing the reasoning path). When the same training used inverted reasoning traces, showing the student model how the frontier model thought through each problem, accuracy rose to 76.0%. A 7.6-percentage-point gain Panfilov et al., 2026.

The behavioral effect showed up in a second experiment. When Kimi-K3 was prefilled with 1% of decoded Opus 4.8 reasoning, its answer style shifted visibly toward Opus on 29 of 30 Humanity's Last Exam problems. The best-of-k n-gram overlap with Opus answers increased by 0.15 on STEM problems, compared to 0.08 on non-STEM problems. Control experiments showed that Inkling received no comparable effect from Opus prefill, and neither Kimi-K3 nor Inkling showed any effect when prefilled with each other's reasoning Panfilov et al., 2026.

A perplexity analysis added one more data point. GLM-5.2 and Kimi-K3 assigned lower perplexity (meaning the text looked more "natural" or expected to those models) to decoded Opus and Sol reasoning than to native reasoning from competitor models Panfilov et al., 2026.

Reasoning Is Now a Targetable, Economically Viable Asset

The IP question for frontier model providers has shifted. Before this research, the concern was output mimicry: a competitor trains on your model's answers and produces a cheaper clone. Output mimicry is a shallow copy. The clone learns what to say but not how to think.

Reasoning trace extraction is a deeper copy. A competitor trains on the internal chain of thought, the step-by-step trajectory that the frontier model follows to reach its answer. For $720 per 10,000 traces, producing a 7.6-point accuracy gain on a standard math benchmark, the economics are straightforward. Any actor building a competitor model can run this at a cost that vanishes into a training budget Panfilov et al., 2026.

The implication for builders: proprietary reasoning is no longer protected by the fact that it's hidden behind encryption. The reasoning itself, not the output, is now the targetable asset. Any provider whose competitive advantage rests on the quality of their chain-of-thought reasoning needs to treat that reasoning as exposed IP, not as a secure internal process.

What Remains Untested: The Production Gap

Three gaps separate this research from a proven production-scale threat.

First, the researchers modeled two attacker positions (first-party users and third-party interceptors) but did not measure how API-level anomaly detection or rate-limiting would affect the attack. A provider that monitors for unusual patterns in reasoning block injection could make the attack more expensive or less reliable. That measurement does not exist in the paper Panfilov et al., 2026.

Second, there is no established corpus-size threshold. The 7.6-point gain came from 10,000 traces. At what point does a distilled model become valuable enough to justify the operational cost and detection risk? The paper does not answer that question, and the answer determines whether this is an academic demonstration or an economic playbook.

Third, extraction error thresholds (the 0.1 error tolerance used for GPT decoding) were not stress-tested against future provider countermeasures. As of August 2026, providers implemented mitigations following disclosure: reasoning blocks are now tied to the producing model and stripped on model switches. But the paper was submitted before those mitigations deployed, so production resilience remains untested Panfilov et al., 2026.

The Structural Ceiling: Encryption Cannot Hide What the Model Must Decrypt

The mitigations above are patches. The deeper problem is architectural, and no patch resolves it.

Whatever model is queried must decrypt and process the contents of prior reasoning tokens. Encrypted reasoning blocks can never be more than semi-hidden. The underlying content remains reachable through the model that holds the decryption key, regardless of transport-level encryption Panfilov et al., 2026.

Think of it like a sealed envelope handed to a translator. The translator must open the envelope to do the translation. No amount of sealing technology changes the fact that the translator reads the contents. The model is the translator.

This means the entire class of cryptographic mitigations assumes the model itself is fully resistant to prompt-based extraction. That assumption breaks down in practice. Large reasoning models that use chain-of-thought are also vulnerable to sensitive information leakage through intermediate reasoning steps, even after standard unlearning procedures like Gradient Ascent, DPO, and KL Minimization Prompt Foo, 2026.

Users should not treat encrypted reasoning blocks as a confidential storage mechanism Panfilov et al., 2026.

Conclusion

The design flaw here was not a bad encryption algorithm. It was a category error: treating reasoning traces as data that can be secured through encryption when the decrypting entity is a language model that can be prompted to reveal its inputs.

Providers disclosed the vulnerability, patched the cross-model replay, and made no public statement about the scope or duration of exposure Tech Times, 2026. The encrypted reasoning model strips users of visibility into how their information is processed, which data influenced the model's actions, where it is retained, and whether they can make informed decisions about data sharing Panfilov et al., 2026.

The question for anyone building on top of these APIs is not whether the patch holds. The question is whether you are treating encrypted reasoning as a security boundary when it was never designed to be one, and whether the model whose reasoning you depend on is one patch away from having its thinking extracted for $720.
